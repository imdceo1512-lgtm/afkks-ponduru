# AFKKS GitHub Pages site

This is a plain HTML, CSS and JavaScript version of the AFKKS Ponduru Khadi website. It has no build step and can be published directly with GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `afkks-ponduru`.
2. Upload the **contents** of this folder, including `index.html`, `styles.css`, `app.js` and `assets/`, to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder, then save.
6. GitHub will display the public website address after deployment.

The enquiry form opens the visitor's email application. Set a recipient address in `app.js` later if AFKKS approves one.
